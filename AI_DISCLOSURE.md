# AI Disclosure

## Which AI tool I used
I used Claude (by Anthropic) to help debug, revise, and improve my initial code drafts.

## My starting point
I began by writing the basic parts of the code myself, using examples and exercises we had covered in class. These initial drafts were my attempt to apply those concepts to the budget manager project.

My first versions were incomplete and did not always run correctly. I used AI during the development process to help work through these problems and refine my attempts.

## How I used AI to refine my drafts
I used Claude in an iterative process: I shared my drafts, explained what I was trying to achieve, and asked for help with parts that were not working.

The assistance included:
- **Debugging:** helping identify errors in my drafts and suggesting changes to make the code run.
- **Explaining corrections:** explaining why a part of my code was failing and how a suggested correction addressed the problem.
- **Refining the logic:** helping revise my initial approach when it did not produce the intended behaviour.
- **Improving clarity:** suggesting clearer ways to express or organise the code so I could follow its logic.
- **Connecting the parts:** helping me understand how the different parts of the program should work together.

This involved going back and forth between my initial attempts and AI suggestions, rather than producing a complete working version in one step.

## Why I used AI
As a beginner, I could start from the examples seen in class, but I sometimes needed help adapting them to this project and understanding why my own versions did not work.

I used AI to support that process, explain problems, and help improve my drafts. I wanted the code to remain close to the concepts covered in class, such as functions, lists, dictionaries, conditionals, loops, and the Python modules used in the assignment.

## Extent of AI involvement
AI contributed corrections, revisions, and suggested code during development. Its role went beyond fixing spelling or formatting: some suggestions affected how parts of the program worked and how the code was organised.

The final project therefore includes both my own initial work and AI-assisted changes. I do not claim that every line of the final version was written independently by me.

## What “refining with AI” means here
I refined the project through prompts, explanations, and revisions to my code drafts. I did not train or technically fine-tune an AI model.

My starting point was my own attempt based on class material, and I used Claude to help develop that attempt into a more complete project.
